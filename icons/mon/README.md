# モンスターの印（任意）

ここに画像を置くと、装備の行の小さな印がその画像に変わります。置かなければ墨の仮の印（オリジナル）が出ます。

- ファイル名：**シリーズ名そのまま**＋拡張子（`png` / `webp` / `jpg`）。例）`融光種ディアネロ.png`、`リオハート.png`
- 正方形・26px角くらいがきれい（透過PNGでもOK）
- **画像を足したり消したりしたら** `python3 tools/icon_manifest.py` を実行して `manifest.json` を作り直す（サイトはこの一覧に載っている画像だけを読む＝余計な404を出さないため）。`manifest.json` を手で直してもよい（`{"リオハート":"png"}` の形）
- ゲーム内アイコン（カプコンの画像）を置くかどうかは運営（あなた）の判断です。融光工房のコードには同梱していません。

## 絵装

絵装の行には、同じモンスターの防具シリーズの印がそのまま出ます（リオレイア → `レイア`、融光種クルルヤック → `融光種クルル` など）。
