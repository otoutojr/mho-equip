# 装備おすすめ ― モンハンアウトランダーズ

冒険ランクと「倒したモンスター」を入れると、いま作れる防具だけでキャラごとの最強5部位を計算する個人用ツールです。iPhoneのホーム画面に追加して使う前提（PWA）。

## できること
- キャラ（主人公の各武器種・SSR/SRキャラ）ごとに、優先スキルの重み付けで最強セットを探索
- どの部位を何レアまで強化すればそのスキルが付くかを表示
- まだ倒していないモンスターを倒した場合の伸びしろ（次に狩るべき相手）
- 入力内容は端末内（localStorage）に保存

## 構成
- `index.html` / `style.css` / `app.js` … 画面
- `solver.js` … Web Worker。候補の絞り込み → 全組み合わせ探索（同点なら強化段数が少ない方）
- `data/*.json` … 防具・スキル・モンスター・キャラの重み
- `tools/build_data.py` … 収集した生データから `data/` を作る

## データについて
防具・スキル・モンスターの情報は攻略サイト（GameWith・Game8）の掲載内容をもとに手作業でまとめたもので、ゲーム内の表記と異なる場合があります。キャラごとの重みは攻略サイトの推奨とゲーム内の効果値を参考にした目安です。
